# PixelDrop PRO 🎨

PixelDrop PRO is a modern, high-performance image gallery website built with a focus on aesthetics, smooth animations, and user interactivity.

## 🚀 Live Demo
Check out the live website here: [https://iac1.github.io/-pixel-drop-/](https://iac1.github.io/-pixel-drop-/)

## ✨ Key Features
- **Modern UI:** Sleek design using Tailwind CSS with dark/light mode support.
- **Dynamic Filtering:** Sort images by categories (Abstract, Cyberpunk, Nature, etc.).
- **Interactive Gallery:** Like/Favorite functionality using Browser LocalStorage.
- **Image Upload:** Users can add their own artwork titles and images locally.
- **Responsive:** Fully optimized for mobile and desktop screens.

## 🛠️ Tech Stack
- **HTML5**
- **Tailwind CSS** (for styling)
- **JavaScript** (for interactivity and logic)
- **GitHub Pages** (for hosting)

## 📸 Project Structure
- `index.html`: Main landing page & gallery engine.
- `categories.html`: Dedicated page for exploring specific themes.
- `favorites.html`: Personalized dashboard for saved artworks.
